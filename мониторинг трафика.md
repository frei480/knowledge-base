```sh
tcpdump -i br-lan -nlq "host 192.168.1.163 and ip" -c 1000 | awk '{print $5}' | sed 's/:$//' | cut -d'.' -f1-4 | sort -u
```

# Пояснения:

1. **Флаги `tcpdump`**:
    - `-i br-lan`: Слушать интерфейс `br-lan`.
    - `-n`: Не преобразовывать адреса в имена (вывод только IP).
    - `-l`: Буферизация вывода (для обработки в реальном времени).
    - `-q`: "Тихий" режим (скрывает порты и лишние детали).
    - Фильтр: `"host 192.168.1.100 and ip"` — только IP-трафик с участием указанного хоста.
        
2. **Обработка вывода**:
    - `awk '{print $5}'`: Извлекает 5-е поле вывода (адрес назначения).
    - `sed 's/:$//'`: Удаляет двоеточие в конце адреса (например, `192.168.1.200:` → `192.168.1.200`).

**Для мониторинга в реальном времени**:
```sh
tcpdump -i br-lan -nlq "src host 192.168.1.163 and ip" | awk '{print $5}' | sed 's/:$//' | grep -v '^192\.168\.1\.163$' | uniq
```
- `uniq`: показывает новые адреса по мере их появления (требует `sort` перед `uniq` для полной уникальности)

# Почему Это Работает:
1. `src host` гарантирует, что анализируются только исходящие соединения
2. `dst host` захватывает только пакеты, где 192.168.1.100 является **адресом назначения** (входящие соединения)
3. `grep -v` исключает:
    - Локальный адрес (если он случайно попал в вывод)
    - Широковещательные адреса (`255.255.255.255`)
    - Multicast-адреса (`224.0.0.0/4`)
4. `sed 's/:$//` очищает остатки портов (`1.2.3.4:` → `1.2.3.4`)
