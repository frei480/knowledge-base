Асимптотика алгоритмов

| Наименование                                         | Ограничение                                   | Разреженный     | Плотный         |
| ---------------------------------------------------- | --------------------------------------------- | --------------- | --------------- |
| BFS                                                  | единичные веса рёбер                          | $O(V^2)$        | $O(V^3)$        |
| Алгоритм Дейкстры, <br>вариант для плотных графов    | неотрицательные веса рёбер                    | $O(V^3)$        | $O(V^3)$        |
| Алгоритм Дейкстры,<br>вариант для разреженных графов | неотрицательные веса рёбер                    | $O(V^2*\log V)$ | $O(V^3*\log V)$ |
| Алгоритм Форда-Беллмана                              | Произвольные веса рёбер                       | $O(V^3)$        | $O(V^4)$        |
| Топологическая сортировка                            | Произвольные веса рёбер,<br>ациклический граф | $O(V^2)$        | $O(V^3)$        |
| Алгоритм Флойда-Уоршелла                             | Произвольные веса рёбер                       | $O(V^3)$        | $O(V^3)$        |
| Алгоритм Джонсона                                    | Произвольные веса рёбер                       | $O(V^2*\log V)$ | $O(V^3*\log V)$ |
