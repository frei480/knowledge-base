> Пусть есть документ. документ обладает свойствами: Тип, Обозначение, Наименование.
>
> и есть словарь для сортировки типов Деталь =1, Чертеж=2, Сборочный чертеж=3, Иснтрукция =4, Лист утверждения=5, Удостоверяющий лист=6.
>
> предписана сортировка списка документов. Сначала по типу, затем по обозначению , затем по наименованию. Но так же лист утверждения и удостоверяющий лист должны быть записаны сразу после документа к которому относятся. Лист утверждения отличается от документа добавленным суффиксом "-ЛУ" в обозначении, удостоверяющий лист отличается от документа добавленным суффиксом "-УЛ".
>
> предложи код на c# как можно остортировать списко таких документов.

Простое применение `OrderBy().ThenBy()` здесь не сработает из-за требования "приклеить" листы утверждения (ЛУ) и удостоверяющие листы (УЛ) к их родительским документам.

Наиболее надежный и понятный подход — это реализовать собственный компаратор (`IComparer<T>`) или, что более современно и гибко в C#, использовать LINQ, но с более сложной логикой построения ключа сортировки.

Разбиваем задачу на логические шаги:
1. **Группировка:** Сначала мы группируем документы. Основной документ, его ЛУ и его УЛ попадают в одну группу. Ключом для группы будет "базовое" обозначение (без суффиксов `-ЛУ` или `-УЛ`).
2. **Сортировка групп:** Затем мы сортируем сами группы между собой по правилам: `Тип -> Обозначение -> Наименование`. Для сортировки группы мы используем данные ее основного документа.
3. **Внутренняя сортировка:** Внутри каждой группы мы расставляем документы в нужном порядке: сначала основной документ, затем ЛУ, затем УЛ.
4. **Объединение:** В конце мы "разворачиваем" отсортированные группы в один плоский список.

Этот подход более надежен и легко читаем, чем попытка создать один очень сложный ключ для `OrderBy`.

# Код На C\#
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

// 1. Определяем класс для документа
public class Document
{
    public string Тип { get; set; }
    public string Обозначение { get; set; }
    public string Наименование { get; set; }

    public override string ToString()
    {
        // Для удобного вывода в консоль
        return $"Тип: {Тип.PadRight(20)} | Обозначение: {Обозначение.PadRight(25)} | Наименование: {Наименование}";
    }
}

public class DocumentSorter
{
    // 2. Словарь для определения порядка сортировки типов
    private static readonly Dictionary<string, int> typeSortOrder = new Dictionary<string, int>
    {
        { "Деталь", 1 },
        { "Чертеж", 2 },
        { "Сборочный чертеж", 3 },
        { "Инструкция", 4 },
        { "Лист утверждения", 5 },
        { "Удостоверяющий лист", 6 }
    };

    private const string LuSuffix = "-ЛУ";
    private const string UlSuffix = "-УЛ";

    // Вспомогательный метод для получения "базового" обозначения
    private static string GetBaseDesignation(string designation)
    {
        if (designation.EndsWith(LuSuffix))
        {
            return designation.Substring(0, designation.Length - LuSuffix.Length);
        }
        if (designation.EndsWith(UlSuffix))
        {
            return designation.Substring(0, designation.Length - UlSuffix.Length);
        }
        return designation;
    }

    // Вспомогательный метод для определения порядка внутри группы (основной документ, ЛУ, УЛ)
    private static int GetInGroupOrder(string designation)
    {
        if (designation.EndsWith(LuSuffix)) return 1; // ЛУ идет вторым
        if (designation.EndsWith(UlSuffix)) return 2; // УЛ идет третьим
        return 0; // Основной документ идет первым
    }

    // 3. Основной метод сортировки
    public static List<Document> SortDocuments(List<Document> documents)
    {
        // Шаг 1: Группируем документы по базовому обозначению
        var groupedByBaseDesignation = documents.GroupBy(doc => GetBaseDesignation(doc.Обозначение));

        // Шаг 2: Сортируем сами группы
        var sortedGroups = groupedByBaseDesignation.OrderBy(group =>
        {
            // Находим основной документ в группе, чтобы по нему сортировать всю группу
            var mainDoc = group.FirstOrDefault(d => !d.Обозначение.EndsWith(LuSuffix) && !d.Обозначение.EndsWith(UlSuffix));
            // Если основного документа нет (например, есть только ЛУ), используем первый попавшийся
            mainDoc ??= group.First(); 
            
            // Получаем порядок типа из словаря. Если тип неизвестен, ставим его в конец.
            typeSortOrder.TryGetValue(mainDoc.Тип, out int typeOrder);
            return typeOrder;

        }).ThenBy(group => group.Key) // group.Key - это и есть базовое обозначение
          .ThenBy(group =>
          {
              var mainDoc = group.FirstOrDefault(d => !d.Обозначение.EndsWith(LuSuffix) && !d.Обозначение.EndsWith(UlSuffix));
              mainDoc ??= group.First();
              return mainDoc.Наименование;
          });

        // Шаг 3 и 4: Сортируем документы внутри каждой группы и объединяем в один список
        var finalSortedList = sortedGroups.SelectMany(group => 
            group.OrderBy(doc => GetInGroupOrder(doc.Обозначение))
        ).ToList();

        return finalSortedList;
    }
}

// Пример использования
public class Program
{
    public static void Main(string[] args)
    {
        var documents = new List<Document>
        {
            new Document { Тип = "Деталь", Обозначение = "АБВГ.758421.002", Наименование = "Втулка" },
            new Document { Тип = "Удостоверяющий лист", Обозначение = "АБВГ.758421.001-УЛ", Наименование = "Удостоверяющий лист" },
            new Document { Тип = "Сборочный чертеж", Обозначение = "АБВГ.301114.001", Наименование = "Блок радиоприемный" },
            new Document { Тип = "Деталь", Обозначение = "АБВГ.758421.001", Наименование = "Ось" },
            new Document { Тип = "Инструкция", Обозначение = "АБВГ.468425.004-И", Наименование = "Инструкция по настройке" },
            new Document { Тип = "Лист утверждения", Обозначение = "АБВГ.301114.001-ЛУ", Наименование = "Лист утверждения" },
            new Document { Тип = "Лист утверждения", Обозначение = "АБВГ.758421.001-ЛУ", Наименование = "Лист утверждения" },
            new Document { Тип = "Чертеж", Обозначение = "АБВГ.123456.001", Наименование = "Схема электрическая" }
        };

        Console.WriteLine("----- Исходный список -----");
        documents.ForEach(Console.WriteLine);

        var sortedDocuments = DocumentSorter.SortDocuments(documents);

        Console.WriteLine("\n----- Отсортированный список -----");
        sortedDocuments.ForEach(Console.WriteLine);
    }
}
```

# Пояснение К Коду:
1. **`Document` class**: Простой класс для хранения данных о документе.
2. **`typeSortOrder` dictionary**: Ключевой элемент для сортировки по типу. Он задает "вес" каждого типа документа.
3. **`GetBaseDesignation()`**: Вспомогательная функция, которая отсекает суффиксы `-ЛУ` и `-УЛ`, чтобы мы могли сгруппировать документ с его листами.
4. **`GetInGroupOrder()`**: Функция, которая задает порядок внутри группы: основной документ (возвращает 0), лист утверждения (1), удостоверяющий лист (2).
5. **`SortDocuments()`**:
    - Сначала `GroupBy` собирает все связанные документы в "пачки" (группы). Например, `АБВГ.758421.001`, `АБВГ.758421.001-ЛУ` и `АБВГ.758421.001-УЛ` попадут в одну группу с ключом `АБВГ.758421.001`.
    - Затем `OrderBy().ThenBy().ThenBy()` сортирует эти группы. Для определения, как сортировать группу, мы находим в ней главный документ и используем его `Тип`, `Обозначение` и `Наименование`.
    - В конце `SelectMany` проходит по отсортированным группам, сортирует документы внутри каждой группы с помощью `GetInGroupOrder` и "распрямляет" их в итоговый единый список.
