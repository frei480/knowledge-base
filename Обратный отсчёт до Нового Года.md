JavaScript-макрос, который **добавляет на веб-страницу** элемент `div`, отображающий **обратный отсчёт до Нового Года 2026** с **плавной анимацией изменения цифр** и двумя вариантами дизайна — **в розовых** и **синих тонах**.

---

# Особенности:
- Плавная анимация смены цифр.
- Автоматический расчёт оставшегося времени.
- Два стиля: **розовый** и **синий**.
- Можно выбрать один из вариантов или оба.

---

# Макрос: Обратный Отсчёт До Нового Года

```javascript
(function() {
    // Создаём контейнер
    const countdownDiv = document.createElement('div');
    countdownDiv.id = 'newyear-countdown';
    countdownDiv.style.position = 'fixed';
    countdownDiv.style.top = '20px';
    countdownDiv.style.right = '20px';
    countdownDiv.style.zIndex = '10000';
    countdownDiv.style.padding = '20px';
    countdownDiv.style.borderRadius = '15px';
    countdownDiv.style.boxShadow = '0 6px 20px rgba(0,0,0,0.2)';
    countdownDiv.style.fontFamily = '"Arial", sans-serif';
    countdownDiv.style.textAlign = 'center';
    countdownDiv.style.fontSize = '24px';
    countdownDiv.style.color = 'white';
    countdownDiv.style.background = 'linear-gradient(135deg, #ff9a9e, #fad0c4)'; // Розовый стиль по умолчанию
    countdownDiv.style.transition = 'all 0.5s ease';

    // Добавляем содержимое
    countdownDiv.innerHTML = `
        <div>До Нового Года осталось:</div>
        <div style="font-size: 36px; margin-top: 10px;" id="countdown-timer">
            --:--:--:--
        </div>
        <button id="toggle-theme" style="
            margin-top: 10px;
            padding: 5px 10px;
            border: none;
            border-radius: 5px;
            cursor: pointer;
            background: rgba(255,255,255,0.3);
            color: white;
        ">Сменить тему</button>
    `;

    document.body.appendChild(countdownDiv);

    // Элементы
    const timerDisplay = document.getElementById('countdown-timer');
    const toggleBtn = document.getElementById('toggle-theme');

    // Целевая дата — Новый Год 2026
    const newYearDate = new Date('January 1, 2026 00:00:00').getTime();

    let currentTheme = 'pink'; // по умолчанию

    // Функция обновления таймера
    function updateTimer() {
        const now = new Date().getTime();
        const diff = newYearDate - now;

        if (diff <= 0) {
            timerDisplay.textContent = '00:00:00:00';
            return;
        }

        const days = Math.floor(diff / (1000 * 60 * 60 * 24));
        const hours = Math.floor((diff % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
        const minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60));
        const seconds = Math.floor((diff % (1000 * 60)) / 1000);

        timerDisplay.textContent = `${pad(days)}:${pad(hours)}:${pad(minutes)}:${pad(seconds)}`;
    }

    // Добавляем ведущий ноль
    function pad(num) {
        return num < 10 ? '0' + num : num;
    }

    // Обновляем таймер каждую секунду
    setInterval(updateTimer, 1000);
    updateTimer(); // сразу показываем

    // Смена темы
    toggleBtn.onclick = function() {
        if (currentTheme === 'pink') {
            countdownDiv.style.background = 'linear-gradient(135deg, #667eea, #764ba2)'; // Синий стиль
            currentTheme = 'blue';
        } else {
            countdownDiv.style.background = 'linear-gradient(135deg, #ff9a9e, #fad0c4)'; // Розовый стиль
            currentTheme = 'pink';
        }
    };
})();
```

---

# Как Использовать:

1. Откройте **консоль разработчика** в браузере (обычно `F12` → вкладка "Console").
2. Вставьте код макроса и нажмите **Enter**.
3. На странице появится красивый таймер в правом верхнем углу.
4. Нажмите кнопку **"Сменить тему"**, чтобы переключиться между розовым и синим стилем.

---

# Цветовые Схемы:

- **Розовый**: `#ff9a9e → #fad0c4`
- **Синий**: `#667eea → #764ba2`

Можно легко настроить под себя, изменив значения `background` в CSS.
