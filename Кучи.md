# Куча
Хранит мультимножество элементов S
Операции:
 - insert x : - добавить x в множество
 - getMin : найти наименьший элемент S
 - extractMin: найти и удалить наименьший элемент из множества
 - decreaseKey ptr $\delta \geq 0$ : ptr - это указатель на элемент. Нужно уменьшить элемент лежащий по адресу ptr на $\delta$
# Heap Sort
сортировка кучей
- insert $a_{1}, a_{2},\dots a_{n}$
- extractMin n раз
Асимптотика: $O(n\log n)$ - сортировка, основанная на сравнениях
