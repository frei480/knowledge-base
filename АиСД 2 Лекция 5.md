# Лекция 5: 2-SAT, Эйлеровы Циклы, DFS В Неориентированных Графах И Мосты

## 1. Задача 2-SAT (2-Satisfiability)

**Постановка задачи:**
Дано $N$ булевых переменных. Есть формула в виде 2-CNF (конъюнктивная нормальная форма), где каждая скобка содержит дизъюнкцию ровно двух литералов (переменных или их отрицаний).
Пример: $(x_1 \lor \neg x_2) \land (\neg x_1 \lor x_3) \dots$
Нужно проверить, существует ли набор значений переменных, при котором формула истинна, и если да — найти его.

**Алгоритм решения:**
1.  **Сведение к импликациям:**
    Дизъюнкция $(A \lor B)$ эквивалентна двум импликациям:
    *   $\neg A \to B$ (если первое ложно, второе обязано быть истинным)
    *   $\neg B \to A$ (если второе ложно, первое обязано быть истинным)

2.  **Построение графа импликаций:**
    *   Строим ориентированный граф с $2N$ вершинами (для каждой переменной $x$ создаем вершины $x$ и $\neg x$).
    *   Для каждой скобки $(A \lor B)$ добавляем в граф ребра $\neg A \to B$ и $\neg B \to A$.
    *   *Свойство:* Если существует путь из $X$ в $Y$, то при $X=1$ обязательно $Y=1$.

3.  **Критерий выполнимости:**
    Формула выполнима $\iff$ для любой переменной $x$ вершины $x$ и $\neg x$ лежат в **разных** компонентах сильной связности (КСС).
    *   *Доказательство:* Если $x$ и $\neg x$ в одной КСС, то $x \to \dots \to \neg x$ и $\neg x \to \dots \to x$. Это требует $x = \neg x$, что невозможно.

4.  **Построение решения:**
    Используем алгоритм Косарайю (или Тарьяна) для поиска КСС и их топологической сортировки. В конденсации графа ребра идут только из компонент с меньшим `ID` (раньше обработанных/топологически левых) в большие (если использовать порядок выхода `tout`).
    *   Пусть `ID[v]` — номер компоненты связности вершины `v` (в топологическом порядке конденсации).
    *   **Правило присвоения:**
        *   Если `ID[x] > ID[not x]`, то $x = 1$ (True).
        *   Иначе $x = 0$ (False).
    *   *Логика:* Мы присваиваем истину тем литералам, которые находятся "правее" в топологической сортировке (из которых не следуют их отрицания).

**Сложность:** $O(N + M)$ (линейная).

> **Примечание:** Для 3-SAT и более (k-SAT, k $\ge$ 3) эффективного алгоритма не существует (NP-трудная задача).

## 2. Эйлеровы Циклы И Пути

**Определения:**
*   **Эйлеров цикл:** Цикл, проходящий по всем ребрам графа ровно по одному разу.
*   **Эйлеров путь:** Путь, проходящий по всем ребрам ровно один раз (начало и конец могут не совпадать).

**Критерий существования (для ориентированного графа):**
Эйлеров цикл существует $\iff$:
1.  Граф сильно связан (если отбросить изолированные вершины).
2.  Для каждой вершины $v$: $in\_degree(v) = out\_degree(v)$ (входящая степень равна исходящей).

**Алгоритм поиска (модифицированный DFS):**
Используем стек для записи ответа.
1.  Запускаем процедуру `Euler(v)`.
2.  Внутри процедуры бежим по исходящим ребрам. Важно удалять (помечать использованными) ребра, чтобы не пройти по ним дважды.
3.  Рекурсивно вызываем `Euler` для конца текущего ребра.
4.  **Важно:** Добавляем вершину (или ребро) в ответный стек **только после возврата из рекурсии** (когда исходящие ребра закончились).

**Оптимизация:**
Чтобы алгоритм работал за $O(E)$, а не за $O(V \cdot E)$, нужно хранить указатель `pt[v]` на первое неиспользованное ребро для каждой вершины (аналогично алгоритму Диница).

**Псевдокод:**
```cpp
Stack S;
void Euler(v):
    while (pt[v] < edges[v].size()):
        edge e = edges[v][pt[v]];
        pt[v]++; // сдвигаем указатель
        Euler(e.to);
        // Добавляем в стек ПОСЛЕ возврата (или само ребро, или вершину)
    S.push(v);
```
Результат — содержимое стека в обратном порядке.

**Эйлеров путь:**
Существует, если граф связан и степени равны у всех, кроме двух вершин:
*   Старт $S$: $out(S) - in(S) = 1$
*   Финиш $T$: $in(T) - out(T) = 1$
*   *Решение:* Добавить фиктивное ребро $T \to S$, найти цикл, затем удалить фиктивное ребро.

## 3. DFS В Неориентированных Графах

В неориентированном графе при обходе в глубину ребра делятся только на два типа:
1.  **Древесные (Tree edges):** Ребра, по которым DFS перешел в новую (непосещенную) вершину. Образуют дерево обхода.
2.  **Обратные (Back edges):** Ребра, ведущие из текущей вершины в уже посещенного предка в дереве обхода.

**Важное свойство:** В неориентированном графе при DFS **не бывает перекрестных ребер** (cross edges) — то есть ребер между разными ветвями дерева. Все недревесные ребра ведут строго вверх к предкам.

**Цвета вершин:**
В неориентированном случае достаточно двух состояний: `visited` (был) и `unvisited` (не был). Серый цвет (в обработке) не так важен для детектирования циклов, как в орграфах, так как любое ребро в уже посещенную вершину (кроме родителя) означает цикл.

## 4. Мосты И Точки Сочленения

**Определения:**
*   **Мост:** Ребро, удаление которого увеличивает количество компонент связности.
*   **Точка сочленения:** Вершина, удаление которой (вместе с инцидентными ребрами) увеличивает количество компонент связности.

### Поиск Мостов За $O(N+M)$

**Идея:** Обратное ребро никогда не может быть мостом (оно лишь дублирует путь по дереву). Мостом может быть только древесное ребро.
Ребро $(u, v)$ (где $v$ — потомок $u$) является мостом, если из поддерева $v$ **нельзя** подняться по обратным ребрам в $u$ или выше.

**Реализация:**
Для каждой вершины в DFS поддерживаем два значения:
1.  `tin[v]` (Time In) — время входа в вершину (таймер увеличивается при каждом заходе в новую вершину).
2.  `ret[v]` (в другой литературе `fup` или `low`) — минимальное время `tin`, до которого можно "дотянуться" из поддерева $v$, сделав **не более одного** прохода по обратному ребру вверх.

**Вычисление `ret[v]`:**
`ret[v]` — это минимум из трех величин:
1.  `tin[v]` (сама вершина).
2.  `tin[p]` для всех обратных ребер $(v, p)$ (прыжок вверх).
3.  `ret[to]` для всех прямых (древесных) ребер $(v, to)$ (минимум, который смогли найти дети).

**Условие моста:**
Древесное ребро $(u, v)$ является мостом, если:
$$ret[v] == tin[v]$$
*(В более общей формулировке $ret[v] > tin[u]$, но так как $ret[v]$ не может быть больше $tin[v]$ по определению минимума, равенство означает, что из $v$ и его потомков нет путей выше $v$).*

**Точки сочленения:**
Алгоритм аналогичен, базируется на тех же значениях `tin` и `ret`. Будет детально разобран на следующей лекции.
