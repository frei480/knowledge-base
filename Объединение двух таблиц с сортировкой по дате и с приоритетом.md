Задача:
пусть у меня есть две таблицы в СУБД в которых хранятся записи о документах я бы хотел объединить их в один список с сортировкой по дате этих документов. можно ли это сделать в python используя очередь с приоритетом?
Замечание:
при совпадении дат нужно учитывать приоритет таблиц. Модифицируем решение, добавив приоритет таблиц в кортеж для кучи. Вот улучшенная версия:

Это очень распространенная и важная задача — определить "вес" или приоритет источника при совпадении основного ключа сортировки.

Проблему можно решить, добавив вторичный ключ для сортировки. Мы можем модифицировать наш `dataclass`, чтобы он учитывал не только дату, но и приоритет таблицы.

**Логика решения:**
1. В `dataclass` **Document** добавим поле `priority`.
2. При создании документов из `table2` будем присваивать им меньший приоритет (например, `0`), а из `table1` — больший (например, `1`).
3. Поскольку `@dataclass(order=True)` сравнивает поля по порядку, мы разместим `priority` сразу после `doc_date`. Теперь, если даты равны, `dataclass` сравнит объекты по полю `priority`, и документ с меньшим значением приоритета (из `table2`) окажется "меньше", то есть раньше в отсортированном списке.

Самое элегантное в этом подходе — **основная функция `merge_sorted_docs` совершенно не изменится**. Вся логика разрешения конфликтов инкапсулируется в самих данных.

# Пример Кода

Вот как это может выглядеть в коде. Для простоты вместо реальных запросов к БД мы будем использовать уже готовые списки. Добавлен новый документ с такой же датой, чтобы наглядно продемонстрировать решение.
```Python
import heapq
from dataclasses import dataclass, field
from datetime import date

# Шаг 1: Модифицируем структуру, добавляя поле priority
# Порядок полей важен: сначала сравнивается doc_date, при равенстве - priority.
@dataclass(order=True)
class Document:
    doc_date: date
    priority: int # Чем меньше значение, тем выше приоритет
    # Остальные поля не участвуют в сравнении
    doc_id: int = field(compare=False)
    source_table: str = field(compare=False)
    content: str = field(compare=False)

# Шаг 2: Симулируем получение данных, присваивая приоритеты
# table2 -> priority=0 (высокий)
# table1 -> priority=1 (низкий)

docs_from_table1 = [
    Document(doc_date=date(2024, 1, 15), priority=1, doc_id=101, source_table='table1', content='...'),
    # Добавим документ с датой, которая совпадет с датой из table2
    Document(doc_date=date(2024, 1, 25), priority=1, doc_id=104, source_table='table1', content='...'),
    Document(doc_date=date(2024, 2, 5), priority=1, doc_id=103, source_table='table1', content='...'),
]

docs_from_table2 = [
    Document(doc_date=date(2024, 1, 10), priority=0, doc_id=201, source_table='table2', content='...'),
    Document(doc_date=date(2024, 1, 25), priority=0, doc_id=202, source_table='table2', content='...'),
    Document(doc_date=date(2024, 3, 1), priority=0, doc_id=203, source_table='table2', content='...'),
]

# Функция слияния остается БЕЗ ИЗМЕНЕНИЙ!
def merge_sorted_docs(*lists):
    merged_list = []
    priority_queue = []
    iterators = [iter(lst) for lst in lists if lst]

    for it in iterators:
        try:
            first_element = next(it)
            heapq.heappush(priority_queue, (first_element, it))
        except StopIteration:
            pass

    while priority_queue:
        doc, source_iterator = heapq.heappop(priority_queue)
        merged_list.append(doc)
        
        try:
            next_element = next(source_iterator)
            heapq.heappush(priority_queue, (next_element, source_iterator))
        except StopIteration:
            pass
            
    return merged_list

# Запускаем слияние
final_sorted_list = merge_sorted_docs(docs_from_table1, docs_from_table2)

# Выводим результат
print("Объединенный список с учетом приоритета таблиц:")
for doc in final_sorted_list:
    print(f"Дата: {doc.doc_date}, ID: {doc.doc_id}, Источник: {doc.source_table} (Приоритет: {doc.priority})")

```

```
Дата: 2024-01-10, ID: 201, Источник: table2 (Приоритет: 0)
Дата: 2024-01-15, ID: 101, Источник: table1 (Приоритет: 1)
Дата: 2024-01-25, ID: 202, Источник: table2 (Приоритет: 0)
Дата: 2024-01-25, ID: 104, Источник: table1 (Приоритет: 1)
Дата: 2024-02-05, ID: 103, Источник: table1 (Приоритет: 1)
Дата: 2024-03-01, ID: 203, Источник: table2 (Приоритет: 0)
```

Обратите внимание на строки с датой **2024-01-25**. Несмотря на то, что оба документа имеют одинаковую дату, документ из `table2` (ID 202) был выведен первым, так как его поле `priority` равно `0`, что "меньше", чем `1` у документа из `table1`.
# Аналогичный Пример С Использованием СУБД

## Алгоритм С Использованием Кучи (Priority Queue)

1. **Предварительная сортировка в БД**:
    Запросите данные из каждой таблицы **уже отсортированные по дате** (используя `ORDER BY date_field`). Это критически важно для работы алгоритма.
2. **Использование итераторов**:
    Для каждой таблицы создайте итератор, который будет возвращать записи по одной.
3. **Куча для слияния**:
    Используйте модуль `heapq` для создания мини-кучи. На каждом шаге извлекайте запись с наименьшей датой и добавляйте в результат.
## Пример Кода
```python
import heapq
import sqlite3  # Для других СУБД используйте соответствующий драйвер

def merge_sorted_tables_with_priority(db_path, table1, table2, date_column, priority_table=2):
    """
    Объединяет две таблицы с сортировкой по дате документов.
    При совпадении дат документы из priority_table (по умолчанию 2) имеют высший приоритет.

    :param db_path: путь к базе данных
    :param table1: имя первой таблицы
    :param table2: имя второй таблицы
    :param date_column: индекс колонки с датой в SELECT
    :param priority_table: приоритетная таблица при совпадении дат (1 или 2)
    :return: объединенный отсортированный список документов
    """
    conn = sqlite3.connect(db_path)
    cursor1 = conn.cursor()
    cursor2 = conn.cursor()
    
    # Запрос данных с сортировкой по дате
    cursor1.execute(f"SELECT * FROM {table1} ORDER BY {date_column}")
    cursor2.execute(f"SELECT * FROM {table2} ORDER BY {date_column}")
    
    # Создание итераторов
    iter1 = iter(cursor1.fetchone, None)
    iter2 = iter(cursor2.fetchone, None)
    
    # Инициализация кучи с учетом приоритета таблиц
    heap = []
    
    # Определение приоритетов
    priority_map = {
        1: 1 if priority_table == 1 else 2,
        2: 1 if priority_table == 2 else 2
    }
    
    # Добавляем первые элементы таблиц в кучу
    for table_idx, iterator in enumerate([iter1, iter2], start=1):
        try:
            record = next(iterator)
            # (дата, приоритет_таблицы, итератор, запись)
            heapq.heappush(
                heap, 
                (record[date_column], priority_map[table_idx], iterator, record)
            )
        except StopIteration:
            pass
    
    # Слияние с помощью кучи
    merged = []
    while heap:
        date, priority, iterator, record = heapq.heappop(heap)
        merged.append(record)
        
        try:
            next_record = next(iterator)
            heapq.heappush(
                heap,
                (next_record[date_column], priority, iterator, next_record)
            )
        except StopIteration:
            continue
    
    conn.close()
    return merged

# Пример использования с приоритетом table2
result = merge_sorted_tables_with_priority(
    db_path="my_database.db",
    table1="documents_1",
    table2="documents_2",
    date_column=2,
    priority_table=2  # Документы из table2 имеют приоритет при совпадении дат
)
```

# Ключевые Моменты:
1. **Приоритет таблиц в кортеже**:
   ```python
   (record[date_column], priority_map[table_idx], iterator, record)
   ```
   Теперь кортеж содержит четыре элемента: дату, приоритет таблицы, итератор и запись.

2. **Система приоритетов**:
   - Высший приоритет = 1 (извлекается первым)
   - Низший приоритет = 2
   - Автоматическое назначение приоритетов на основе параметра `priority_table`

3. **Логика сравнения**:
   - Сначала сравниваются даты
   - При равных датах сравниваются приоритеты таблиц (меньшее число = высший приоритет)
   - При совпадении и дат, и приоритетов порядок не гарантирован (но в реальности приоритеты таблиц всегда разные)

# Как Это Работает При Совпадении Дат:
1. Для документов из table2 устанавливается приоритет 1
2. Для документов из table1 устанавливается приоритет 2
3. При совпадении дат кортеж с приоритетом 1 (table2) будет извлечен первым из кучи

# Особенности Реализации:
1. **Гибкость приоритетов**:
   ```python
   # priority_table=2 означает, что table2 имеет высший приоритет
   priority_map = {
        1: 1 if priority_table == 1 else 2,  # Для table1
        2: 1 if priority_table == 2 else 2   # Для table2
   }
   ```

2. **Эффективность**:
   - Сохраняется потоковая обработка (O(log k) на операцию)
   - Память: O(k), где k = количество таблиц (в данном случае 2)

3. **Расширяемость**:
   - Легко добавить поддержку большего числа таблиц
   - Можно модифицировать систему приоритетов

# Пример Работы:
Допустим, у нас есть документы:
- table1: [doc1 (2023-01-01), doc3 (2023-01-03)]
- table2: [doc2 (2023-01-01), doc4 (2023-01-02)]

Результат слияния с приоритетом table2:
1. doc2 (2023-01-01, table2) - высший приоритет при совпадении дат
2. doc1 (2023-01-01, table1)
3. doc4 (2023-01-02, table2)
4. doc3 (2023-01-03, table1)

Это решение гарантирует, что при совпадении дат документы из указанной таблицы (в данном случае table2) всегда будут идти первыми.
