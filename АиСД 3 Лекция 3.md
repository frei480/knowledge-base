# Лекция 3: Суффиксный Массив И Его Применения

## 1. Определение И Основные Понятия

**Суффиксный массив ($P$)** — это лексикографически отсортированный массив всех суффиксов строки $S$.
*   Пусть $S^{(i)}$ — суффикс, начинающийся с позиции $i$.
*   Массив $P = [P_0, P_1, \dots, P_{n-1}]$ — это перестановка индексов такая, что суффиксы в этом порядке возрастают: $S^{(P_0)} < S^{(P_1)} < \dots < S^{(P_{n-1})}$.

**LCP (Longest Common Prefix)** — длина наибольшего общего префикса двух строк.
*   Для суффиксного массива вводится вспомогательный массив $LCP$, где $LCP[i]$ — это длина общего префикса между соседними в массиве $P$ суффиксами: $S^{(P_i)}$ и $S^{(P_{i+1})}$.

### Свойство LCP На Отрезке
Чтобы найти LCP между любыми двумя суффиксами $S^{(P_i)}$ и $S^{(P_j)}$ ($i < j$), нужно взять **минимум** значений LCP на отрезке между ними в суффиксном массиве:
$$\text{LCP}(S^{(P_i)}, S^{(P_j)}) = \min(LCP[i], LCP[i+1], \dots, LCP[j-1])$$
*Это позволяет сравнивать любые две подстроки за $O(1)$ после построения Sparse Table на массиве LCP.*

## 2. Алгоритм Построения Суффиксного Массива За $O(n \log n)$

Для удобства к строке $S$ в конец добавляется уникальный символ `$` (или `#`), который меньше любого символа алфавита. Это позволяет заменить задачу сортировки суффиксов задачей сортировки **циклических сдвигов**.

### Основная Идея: Метод Удвоения
Мы сортируем подстроки длиной $2^k$, постепенно увеличивая $k$ (0, 1, 2…).
1.  **База ($k=0$):** Сортируем одиночные символы (подстроки длины 1) с помощью **стабильной сортировки подсчетом**. Каждой позиции $i$ присваиваем класс эквивалентности $C[i]$ (равные символы — один класс, меньший символ — меньший номер класса).
2.  **Переход ($k \to k+1$):**
    *   Подстрока длины $2^{k+1}$, начинающаяся в $i$, состоит из двух половин длины $2^k$: левой (с индекса $i$) и правой (с индекса $i + 2^k$).
    *   У нас уже есть классы эквивалентности для этих половин. Значит, подстрока длины $2^{k+1}$ задается парой чисел: $(C[i], C[i + 2^k])$.
    *   Сортируем эти пары за $O(n)$.
    *   **Оптимизация сортировки пар:**
        1. Сначала сортируем по второй координате. Это можно сделать мгновенно, просто вычтя $2^k$ из текущего массива $P$.
        2. Затем выполняем стабильную сортировку подсчетом по первой координате.
    *   Обновляем классы эквивалентности $C$.

**Итоговая сложность:** $\log n$ этапов, каждый за $O(n)$, итого $O(n \log n)$.

## 3. Алгоритм Касаи (построение LCP За $O(n)$)

После того как суффиксный массив $P$ построен, нужно вычислить LCP для соседей. Наивное сравнение заняло бы $O(n^2)$. Алгоритм Касаи делает это за линию.

**Идея:** будем вычислять LCP для суффиксов не в порядке массива $P$, а в порядке их расположения в исходной строке (от длинного к короткому).
1.  Если для суффикса $S^{(i)}$ мы нашли, что его LCP с соседом в массиве $P$ равно $k$, то для суффикса $S^{(i+1)}$ (отбросили первый символ) LCP с его новым соседом будет **не меньше $k-1$**.
2.  Это позволяет не начинать сравнение с нуля, а проверять совпадение символов, начиная с позиции $k-1$.
3.  За счет того, что значение $k$ за весь алгоритм уменьшается не более $n$ раз, а увеличивается только при совпадении символов, суммарное время работы — $O(n)$.

## 4. Прикладное Применение: Дедупликация Данных

Суффиксный массив используется в современных задачах машинного обучения (статья 2022 года "Deduplicating Training Data").
*   При обучении языковых моделей (LLM) на терабайтах текста часто встречаются дубликаты (бессмысленные фразы, скопированные тысячи раз).
*   С помощью суффиксного массива можно быстро сгруппировать все одинаковые подстроки большой длины. Если в массиве классов эквивалентности $C$ для определенной длины (например, 64 символа) виден длинный блок одинаковых значений — это дубликат, который следует удалить, чтобы не портить обучение.

## 5. Дополнительная Лемма: Количество Палиндромов

В конце лекции была доказана важная лемма для будущих тем (дерево палиндромов):
**В строке длины $n$ существует не более $n$ различных подстрок-палиндромов.**
*   *Доказательство:* При добавлении одного символа к строке количество новых различных палиндромов может увеличиться максимум на 1. Если при добавлении символа `C` образуется два новых суффикса-палиндрома, то меньший из них обязательно уже встречался внутри большего (в силу симметрии), а значит, не является "новым".

---
**Основные структуры данных:**
*   `P[i]` — индекс начала $i$-го в порядке сортировки суффикса.
*   `C[i]` — ранг (класс эквивалентности) суффикса, начинающегося в $i$.
*   `LCP[i]` — длина общего префикса между `P[i]` и `P[i+1]`.
