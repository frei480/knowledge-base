Исключение `System.ArgumentException: 'An item with the same key has already been added.'` (Такой ключ уже добавлен) — это очень распространенная проблема при использовании `ToDictionary()` в LINQ, когда в исходной коллекции есть дублирующиеся ключи.
Словарь по своей природе требует, чтобы все ключи были уникальными. Поэтому, чтобы избежать исключения, вам нужно заранее решить, как поступать с дубликатами. Вот несколько самых популярных стратегий и способов их реализации.
Давайте представим, что у нас есть вот такой список объектов:

```csharp
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
}

var products = new List<Product>
{
    new Product { Id = 1, Name = "Книга", Price = 500 },
    new Product { Id = 2, Name = "Телефон", Price = 40000 },
    new Product { Id = 1, Name = "Книга (новое издание)", Price = 750 }, // <-- Дубликат по Id
    new Product { Id = 3, Name = "Наушники", Price = 2500 }
};
```

При попытке выполнить `products.ToDictionary(p => p.Id);` мы получим исключение из-за дубликата ключа `1`.

---

### Решение 1: Оставить последний элемент (перезаписать ключ)

Это самый частый сценарий: если ключ встречается несколько раз, мы хотим, чтобы в словаре осталось значение от последнего встреченного элемента.

Стандартный `ToDictionary` не имеет встроенной опции "перезаписать". Самый эффективный и читаемый способ — это использовать `GroupBy`, а затем взять последний элемент из каждой группы.

```cs
// Группируем по ключу, а затем для каждой группы создаем пару ключ-значение,
// выбирая последний элемент из группы в качестве значения.
var dictionary = products
    .GroupBy(p => p.Id) // Группируем все продукты по их Id
    .ToDictionary(
        g => g.Key, // Ключ группы (Id) становится ключом словаря
        g => g.Last() // Последний элемент из группы становится значением
    );

// Результат:
// { 1, Product("Книга (новое издание)", 750) }
// { 2, Product("Телефон", 40000) }
// { 3, Product("Наушники", 2500) }
```

**Почему это работает:** `GroupBy` создает группы элементов с одинаковым ключом. Затем мы проходим по этим группам и для каждой создаем одну запись в словаре, гарантируя уникальность ключей.

---
### Решение 2: Оставить первый элемент

Если вам нужно сохранить значение первого встреченного элемента, а последующие дубликаты игнорировать, логика очень похожа на предыдущую, но вместо `Last()` используется `First()`.

```cs
var dictionary = products
    .GroupBy(p => p.Id)
    .ToDictionary(
        g => g.Key,
        g => g.First() // Первый элемент из группы становится значением
    );

// Результат:
// { 1, Product("Книга", 500) }
// { 2, Product("Телефон", 40000) }
// { 3, Product("Наушники", 2500) }
```
#### Альтернатива для .NET 6+ (`DistinctBy`)
В .NET 6 и новее появился удобный метод `DistinctBy`, который делает этот сценарий еще проще и читаемее. Он оставляет только первый уникальный элемент по указанному свойству.

```cs
// Доступно в .NET 6 и выше
var dictionary = products
    .DistinctBy(p => p.Id) // Оставляем только первые уникальные элементы по Id
    .ToDictionary(p => p.Id); // Теперь ToDictionary не вызовет исключения

// Результат будет таким же, как в примере с GroupBy и First()
```

### Решение 3: Собрать все значения для одного ключа
Иногда нужно не отбросить дубликаты, а собрать все значения, соответствующие одному ключу. Для этой цели идеально подходит не `Dictionary<TKey, TValue>`, а `Lookup<TKey, TElement>` или `Dictionary<TKey, List<TValue>>`.
#### Способ 3.1: Использование `ToLookup`

`ToLookup` — это структура данных, похожая на словарь, но специально созданная для хранения нескольких значений для одного ключа. Это самый простой способ.
```cs
var lookup = products.ToLookup(p => p.Id);

// Теперь вы можете получить все продукты с Id = 1
// IEnumerable<Product> books = lookup[1];
// foreach(var book in books)
// {
//     Console.WriteLine(book.Name); // Выведет "Книга" и "Книга (новое издание)"
// }
```
#### Способ 3.2: Создание `Dictionary<int, List<Product>>`
Если вам по какой-то причине нужен именно `Dictionary`, вы можете сделать это с помощью `GroupBy`.
```cs
var dictionaryWithLists = products
    .GroupBy(p => p.Id) // Группируем
    .ToDictionary(
        g => g.Key, // Ключ остается тот же
        g => g.ToList() // Значением становится список всех элементов группы
    );

// Результат:
// { 1, List<Product> [ Product("Книга"), Product("Книга (новое издание)") ] }
// { 2, List<Product> [ Product("Телефон") ] }
// { 3, List<Product> [ Product("Наушники") ] }
```

### Сводная таблица решений

| Задача                                        | Решение                                                      | Когда использовать                                                                 |
| --------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **Оставить последний элемент** (перезаписать) | `GroupBy(...)` + `ToDictionary(g => g.Key, g => g.Last())`   | Самый частый случай. Нужно получить словарь, где старые значения заменены новыми.  |
| **Оставить первый элемент** (игнорировать)    | `GroupBy(...)` + `ToDictionary(g => g.Key, g => g.First())`  | Нужно сохранить данные от первого вхождения, а дубликаты проигнорировать.          |
| **Оставить первый элемент** (для .NET 6+)     | `DistinctBy(p => p.Id).ToDictionary(...)`                    | Более современный и лаконичный способ для .NET 6 и выше.                           |
| **Собрать все дубликаты**                     | `ToLookup(p => p.Id)`                                        | Нужно работать со всеми значениями для каждого ключа. `Lookup` для этого и создан. |
| **Собрать все дубликаты в словарь**           | `GroupBy(...)` + `ToDictionary(g => g.Key, g => g.ToList())` | Если по требованиям нужен именно `Dictionary<TKey, List<TValue>>`.                 |
