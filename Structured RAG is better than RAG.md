00:08 Введение и контекст

01:11 Идея структурированного диалога

• Структурированный диалог лучше обычного благодаря более длительным разговорам, обработке большего количества запросов и точности.
• Упоминаются вклад Стивена Луко и Умеша Мадана в разработку.

02:10 Память и поиск документов

• Агентам нужна память для прошлых взаимодействий.
• Поиск документов важен для агентов, имеющих доступ к большому количеству данных.
• Технология встраивания текста используется для хранения данных.

03:19 Процесс встраивания

• Для получения встраивания делается запрос к серверу LLM.
• Встраивание текста представляет собой вектор из чисел с плавающей запятой.
• Векторы хранятся в векторной базе данных.

05:06 Поиск в векторной базе данных

• Вопрос отправляется на сервер встраивания, в ответ получается вектор.
• Вычисляется скалярное произведение векторов для определения ближайших соседей.
• Пример с миллионом векторов показывает, что это занимает много места.

07:52 Недостатки векторных баз данных

• Векторные базы данных сложны, дороги и занимают много места.
• Оптимизация количества векторов может привести к размытым результатам.
• Процент отзыва для векторных баз данных составляет около 60%.

08:53 Структурированный текст и ИИ

• Вместо встраивания используется структурированный текст.
• ИИ извлекает знания из текста, представляя объекты, действия, темы и отношения.
• Знания сохраняются в классической базе данных SQL.

10:02 Ввод данных и запросы

• Данные вводятся с помощью ИИ с конкретной подсказкой.
• Схема представлена в виде набора типов и интерфейсов TypeScript.
• ИИ генерирует JSON-запрос, который можно перевести на SQL.

11:56 Конвейер запросов

• Вопрос пользователя превращается в JSON-запрос.
• Из базы данных извлекаются «кусочки знаний».
• LLM преобразует данные в естественный английский ответ.

13:59 Преимущества структурированного подхода

• Структурированный подход позволяет лучше запоминать и точнее определять информацию.
• Индексация данных заранее снижает нагрузку на запросы.
• Возможность делать выводы на основе «кусочков» знаний.

16:17 Демонстрация

17:10 Технические проблемы и их решение

• Совет перетащить окно вправо для отображения на телевизоре.
• Попытка решения проблемы с отображением текста.

19:02 Проверка работы системы

• Отсутствие истории разговоров в пользовательском интерфейсе.
• Упоминание о невозможности ссылки на «альбатроса».

22:14 Демонстрация индексации сообщений

• Индексация около 500 сообщений из электронной почты.
• Необходимость использования «send» вместо «say» для индексации.
