In binary trees, **tree traversal** methods determine the order in which nodes are visited. The three primary **depth-first traversal** techniques are:

---
# 1. **In-order Traversal (Left → Root → Right)**
**Order:**
1. Traverse the left subtree
2. Visit the root node
3. Traverse the right subtree

**Usage:**
- Retrieves values in **sorted order** for **Binary Search Trees (BSTs)**
**Example:**
```
    2
   / \
  1   3
```
**In-order:** `1, 2, 3`

---
# 2. **Pre-order Traversal (Root → Left → Right)**
**Order:**
1. Visit the root node
2. Traverse the left subtree
3. Traverse the right subtree

**Usage:**
- Used to **copy or serialize** a tree
- Useful for prefix expression construction
**Example:**
```
    2
   / \
  1   3
```

**Pre-order:** `2, 1, 3`

---

# 3. **Post-order Traversal (Left → Right → Root)**

**Order:**
1. Traverse the left subtree
2. Traverse the right subtree
3. Visit the root node

**Usage:**
- Used to **delete or free** a tree
- Helpful for evaluating postfix expressions

**Example:**
```
    2
   / \
  1   3
```
**Post-order:** `1, 3, 2`
