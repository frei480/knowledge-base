# Лекция 4: Дерево Палиндромов И Суффиксный Автомат (Введение)

## Часть 1. Дерево Палиндромов (Eertree)

### 1. Идея И Структура
Задача: эффективно хранить информацию обо всех **различных** подстроках-палиндромах строки $S$.
Хранить палиндромы целиком в обычном боре — дорого по памяти ($O(N^2)$ в худшем случае).

**Решение:**
*   Храним только **правую половину** палиндрома (так как он симметричен).
*   Используем **два дерева** (два корня):
    1.  **Корень нечетных палиндромов (Odd Root):** соответствует «мнимому» палиндрому длины **-1**. Это технический трюк: если к нему «приписать» букву $X$ с обеих сторон, «черная дыра» длины -1 поглотит один $X$, и получится палиндром длины 1 (просто $X$).
    2.  **Корень четных палиндромов (Even Root):** соответствует пустому палиндрому длины **0**.
*   Каждая вершина дерева соответствует уникальному палиндрому.
*   В вершине храним:
    *   `len`: длину палиндрома.
    *   `link`: суффиксную ссылку (см. ниже).
    *   `next[c]`: переходы по символам (добавление символа $c$ с обеих сторон палиндрома).

### 2. Построение (Online-алгоритм)
Строим дерево, добавляя символы строки $S$ по одному слева направо.
**Факт:** При добавлении одного символа к строке появляется **максимум 1 новый** палиндром (это самый длинный палиндром, являющийся суффиксом новой строки).

**Алгоритм добавления символа $C$ (на позиции $i$):**
Поддерживаем указатель $V$ на вершину, соответствующую **максимальному суффиксу-палиндрому** предыдущей версии строки.

1.  **Поиск места вставки:**
    Нужно найти такой суффикс-палиндром $P$ (из уже существующих), который можно расширить символом $C$. То есть проверяем условие:
    $$S[i - len(P) - 1] == S[i]$$
    Если условие не выполняется, переходим по суффиксной ссылке: $V = V.link$. Повторяем, пока не найдем подходящий.
    *(Для нечетного корня условие выполняется автоматически, так как $len = -1$, и мы сравниваем символ сам с собой).*

2.  **Создание новой вершины:**
    *   Если у найденной вершины $V$ уже есть переход по $C$, просто переходим в него (новый палиндром не возник).
    *   Если перехода нет — создаем новую вершину $New$.
        *   Длина новой вершины: $len(New) = len(V) + 2$.

3.  **Вычисление суффиксной ссылки (`link`):**
    *   Суффиксная ссылка ведет в **максимальный собственный суффикс-палиндром** текущего палиндрома.
    *   Чтобы найти `link` для $New$, берем `link` от родителя ($V$) и снова прыгаем по суффиксным ссылкам, пока не найдем палиндром, который можно расширить символом $C$ (то же условие $S[i - len - 1] == S[i]$).
    *   Ссылка из новой вершины ведет в найденный узел + переход по $C$.
    *   *Частный случай:* Ссылка из узла длины 1 (например, «a») ведет в чётный корень (0). Ссылка из чётного корня ведет в нечётный (-1).

### 3. Асимптотика
*   **Время и память:** $O(N)$ (линейно от длины строки).
*   **Обоснование:** Глобальный указатель на текущий максимальный суффикс-палиндром движется "вглубь" (увеличивая длину) только при добавлении символа (максимум $N$ раз). Циклы `while` по суффиксным ссылкам уменьшают длину. Суммарно количество спусков и подъемов линейно.

## Часть 2. Суффиксный Автомат (Suffix Automaton) — Введение

### 1. Определение
**Суффиксный автомат** для строки $S$ — это ориентированный ациклический граф (DAWG), который является детерминированным конечным автоматом.
*   Он распознает язык $L$, состоящий из **всех суффиксов** строки $S$.
*   Мы строим **минимальный** такой автомат.
*   Хотя он строится для суффиксов, он неявно хранит информацию обо всех подстроках (любая подстрока — префикс какого-то суффикса).

### 2. Правый Контекст И Классы Эквивалентности
Для понимания структуры автомата вводятся понятия:
*   **Правый контекст** строки $\alpha$ ($R(\alpha)$): множество всех строк $\beta$, таких что $\alpha\beta$ является суффиксом $S$. Грубо говоря, это все способы «дописать» $\alpha$ до конца строки $S$.
*   **Эквивалентность строк:** Две строки $\alpha$ и $\gamma$ эквивалентны ($\alpha \equiv \gamma$), если их правые контексты совпадают ($R(\alpha) = R(\gamma)$).

**Теорема Майхилла — Нероуда (адаптация):**
Вершины минимального автомата взаимно однозначно соответствуют **классам эквивалентности** по этому отношению.

### 3. Свойства Классов Эквивалентности
1.  **Вложенность:** Если $R(u) = R(v)$, то одна из строк обязательно является суффиксом другой.
2.  **Структура класса:** Каждый класс эквивалентности (одна вершина автомата) содержит набор подстрок.
    *   В классе есть **самая длинная** строка ($longest$).
    *   Все остальные строки в этом классе — это её суффиксы.
    *   Причем это **непрерывный диапазон** длин суффиксов. (Например, в классе могут лежать строки: `abcde`, `bcde`, `cde`).
3.  **Endpos:** Правый контекст фактически определяется множеством позиций в строке $S$, где заканчиваются вхождения подстроки. Если у подстрок одинаковые позиции окончаний вхождений, они в одном классе.

### 4. Структура Автомата
*   **Вершины:** Классы эквивалентности.
*   **Ребра:** Переходы по символам. Переход из класса $C_1$ в $C_2$ по символу $c$ существует, если для строки из $C_1$ приписывание $c$ переводит нас в строку из $C_2$.
*   Размер автомата (количество вершин и ребер) линеен $O(N)$, что делает его мощным инструментом для решения задач на строки.
