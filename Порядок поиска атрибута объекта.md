### Дескрипторы в Python 3 и порядок поиска атрибута объекта

Дескрипторы — это мощный механизм в Python, позволяющий настраивать поведение доступа к атрибутам объекта. По сути, дескриптор — это объект, который управляет доступом к атрибуту другого объекта.

**Что такое дескриптор?**

Объект является дескриптором, если он определяет один или несколько из этих "магических" методов:

- __get__(self, instance, owner): Вызывается при получении атрибута.
    - self: Сам экземпляр дескриптора.
    - instance: Экземпляр объекта, из которого запрашивается атрибут (например, my_object.attribute). Если доступ осуществляется через класс (MyClass.attribute), то instance будет None.
    - owner: Класс, которому принадлежит instance (например, MyClass).
- __set__(self, instance, value): Вызывается при установке атрибута.
    - self: Сам экземпляр дескриптора.
    - instance: Экземпляр объекта, в котором устанавливается атрибут.
    - value: Новое значение, которое присваивается атрибуту.
- __delete__(self, instance): Вызывается при удалении атрибута.
    - self: Сам экземпляр дескриптора.
    - instance: Экземпляр объекта, в котором удаляется атрибут.

**Типы дескрипторов:**
1. **Неперезаписываемые дескрипторы (Non-data descriptors)**: Определяют только __get__. Примером являются методы функций.
2. **Перезаписываемые дескрипторы (Data descriptors)**: Определяют __set__ (и, возможно, __get__ и __delete__). Их наличие имеет более высокий приоритет в поиске атрибутов, чем записи в словаре экземпляра.

**Пример дескриптора:**
Представим дескриптор для проверки типа значения:
```python
class TypeChecker:
	def __init__(self, expected_type):
		self.expected_type = expected_type
		self._value = None # Здесь будет храниться реальное значение
	
	def __get__(self, instance, owner):
		if instance is None: 
			return self
		print(f"Getting value for {owner.__name__}. (Expected: {self.expected_type})") 
		return self._value 
	
	def __set__(self, instance, value): 
		if not isinstance(value, self.expected_type): 
			raise TypeError(f"Expected {self.expected_type}, got {type(value)}")
		print(f"Setting value for {instance.__class__.__name__}. (Value: {value})")
		self._value = value
	
	def __delete__(self, instance):
		print(f"Deleting value for {instance.__class__.__name__}.") 
		del self._value 

class MyClass: 
	age = TypeChecker(int) 
	name = TypeChecker(str)
	 
obj = MyClass()
obj.age = 30 
obj.name = "Alice" 
print(f"Age: {obj.age}") 
print(f"Name: {obj.name}") 
# obj.age = "thirty" # Это вызовет TypeError
```

В этом примере `TypeChecker` выступает как перезаписываемый дескриптор, который гарантирует, что атрибуты age и name в MyClass будут иметь соответствующий тип.

**Порядок поиска атрибута объекта (Method Resolution Order - MRO):**

Когда вы обращаетесь к атрибуту obj.attr, Python выполняет следующий порядок поиска:

1. **Дескрипторы данных в классе:** Python проверяет, является ли `attr` дескриптором данных (т.е. имеет `__set__`) в словаре класса `obj.__class__.__dict__`. Если да, то вызывается метод `__get__` этого дескриптора. **Это имеет наивысший приоритет.**
    
2. **Словарь экземпляра:** Если `attr` не является дескриптором данных, Python ищет `attr` в словаре экземпляра `obj.__dict__`. Если атрибут найден, его значение возвращается.
    
3. **Дескрипторы без данных в классе:** Если attr не найден в `obj.__dict__`, Python ищет его в словаре класса `obj.__class__.__dict__` (и его базовых классов в соответствии с MRO). Если `attr` найден и является дескриптором без данных (имеет только `__get__`), то вызывается `__get__` этого дескриптора.
    
4. **Словарь класса (и базовых классов):** Если `attr` не является дескриптором и не найден в словаре экземпляра, Python ищет его как обычный атрибут в словаре класса `obj.__class__.__dict__` (и его базовых классах по MRO). Если атрибут найден, его значение возвращается.
    
5. **__getattr__:** Если атрибут не найден ни в одном из вышеперечисленных мест, Python проверяет, определен ли метод `__getattr__(self, name)` в классе объекта. Если да, то он вызывается, и его результат возвращается.
    
6. **AttributeError:** Если ни один из этих шагов не находит атрибут, генерируется исключение AttributeError.

**Ключевой момент:** Дескрипторы данных имеют приоритет над атрибутами, хранящимися непосредственно в __dict__ экземпляра. Это позволяет дескрипторам "перехватывать" и контролировать доступ к атрибутам, даже если в экземпляре существует запись с таким же именем.

Дескрипторы являются фундаментальной частью реализации многих стандартных функций Python, таких как методы (Bound Methods), property, staticmethod и classmethod. Понимание дескрипторов помогает глубже понять внутреннюю работу Python и позволяет писать более гибкий и мощный код.
