# Обзор Используемого Технологического Стека: Инструменты И Платформы

## 1. Обзор Технического Стека Для ИИ
Автор придерживается **AI‑first подхода** к разработке ПО — считает, что в современных условиях это единственно верный путь. Его стек стабилен: основные инструменты не меняются уже больше года. Ключевой принцип: _capabilities over tools_ («возможности важнее инструментов»).

**Главная рекомендация:** найти набор инструментов, который хорошо работает для вас, и придерживаться его, сохраняя гибкость для решения специфических задач.

## 2. Ядро Технического Стека
Основа стека — технологии, применимые к любому ПО:
- **База данных:** PostgreSQL (через Neon или Supabase).
    - _Альтернативы:_ MongoDB, Firestore (но автор перешёл на SQL из‑за стандартов индустрии, лучшего понимания LLM и вопросов ценообразования).
    - _Почему PostgreSQL:_ стандарт для AI‑агентов, масштабируемость, совместимость с PG Vector (векторная база данных).
- **Кэширование:** Redis (быстрый, удобный).
    - _Альтернатива:_ Valky (open‑source, совместим с Redis).
- **AI‑ассистент для кода:** Claude Code (основной инструмент, открыт почти постоянно).
    - _Альтернативы:_ Cursor 2.0, Codeex (но Claude Code пока лидирует по функционалу).
- **No‑code для прототипирования:** n8n (любимый инструмент для быстрой проверки идей).
    - _Альтернативы:_ Langflow, Flowwise.
- **Мониторинг агентов:** Langfuse (обязателен для продакшена).
    - _Альтернативы:_ Langsmith, Helone (но Langfuse — самый функциональный и open‑source).

## 3. Основной Стек Для Моих Агентов ИИ
Ключевые инструменты для создания AI‑агентов:
- **Фреймворк для агентов:** Pyantic AI (гибкость, поддержка новых протоколов: MCPU, A2A, AGUI).
    - _Почему не raw LLM calls?_ Pyantic AI упрощает работу со множеством провайдеров без потери контроля.
- **Мультиагентные системы:** Langraph (управление сложными workflow, визуализация графов).
    - _Альтернатива:_ Crew AI (но Langraph зрелее для human‑in‑the‑loop).
- **Авторизация и безопасность:** Arcade (управление доступом к аккаунтам пользователей).
    - _Особенность:_ SDK для MCP‑серверов с встроенной авторизацией.
- **Наблюдаемость:** Langfuse (анализ токенов, стоимости, латентности, вызовов инструментов).

## 4. Инструменты Для Агентов RAG
Инструменты для RAG (Retrieval‑Augmented Generation):
- **Извлечение данных:**
    - Dockling (для сложных документов: PDF, Excel).
    - Crawl for AI (для веб‑данных: очистка, LLM‑интеграции).
- **Хранение:** PostgreSQL + PG Vector (компромисс между SQL и векторной БД).
    - _Альтернативы:_ Quadrant, Pinecone (быстрее, но дороже).
- **Долгосрочная память:** Mem Zero (интеграция с PG Vector, простота внедрения).
    - _Альтернатива:_ Zep (но не open‑source).
- **Графы знаний:**
    - Neo4j (база данных: UI, скорость, масштабируемость).
    - Graffiti (библиотека для извлечения сущностей и связей).
    - _Альтернатива для графов:_ Light RAG (но Graffiti фокусируется только на графах).
- **Оценка RAG:** Raos (метрики: faithfulness, relevance, генерация тестовых данных).
- **Веб‑поиск:** Brave (приватность, быстрый AI‑поиск), Perplexity (детальный, но медленнее).

## 5. Инструменты Для Агентов Веб-автоматизации
Инструменты для автоматизации работы с веб‑данными:
- **Извлечение в реальном времени:** Crawl for AI (open‑source, быстрый).
    - _Альтернатива:_ Firecrawl.
- **Социальные платформы:** Ampify, Bright Data (для LinkedIn, X, Instagram).
- **Браузерная автоматизация:**
    - Playwright (мультибраузерная поддержка, MCP‑сервер для AI‑ассистентов).
    - Puppeteer, Selenium (но Playwright предпочтительнее).
- **Управление браузером:** Browserbase (запись сессий, анти‑бот‑защита, Director для навигации).

## 6. Технический Стек Для Разработки Приложений Full Stack
Стек для полноценной разработки:
- **API:** FastAPI (Python‑фреймворк, богатый функционал).
    - _Альтернатива:_ Flask (проще), Express (для TypeScript).
- **База данных:** PostgreSQL.
- **Аутентификация:**
    - Supabase (простая аутентификация).
    - Ozero (enterprise‑решения: MFA, SSO, SAML).
    - _Альтернативы:_ Clerk, Octa.
- **Фронтенд:** React + Vite (быстро, легковесно).
    - _Альтернативы:_ Next.js (сложности с обновлениями), Vue.
- **Компоненты/стили:** Shad CN + Tailwind CSS.
- **Генерация UI:** Lovable (AI‑ассистент для красивых интерфейсов).
    - _Альтернативы:_ Bolt New, Bolt.diy (open‑source).
- **Прототипирование UI:** Streamlit (Python‑интерфейсы без бэкенда).
- **Аналитика:** Sentry (реал‑тайм, AI‑функции).
    - _Альтернатива:_ Post Hog, Google Analytics.
- **Платежи:** Stripe (лучший developer experience).
    - _Альтернативы:_ Lemon Squeezy, Paddle.

## 7. Инструменты/платформы Для Развертывания И Инфраструктуры
Инструменты для деплоя и инфраструктуры:
- **PaaS:** Render (простота, YAML для инфраструктуры, git‑деплой).
    - _Альтернативы:_ Fly.io, Netlify.
- **Облака:** Google Cloud (GCP) для enterprise‑требований, Runpod (GPU‑нагрузки).
    - _Альтернативы для GPU:_ Tensor Dock (дешевле, но менее стабильно), Lambda Labs.
- **Виртуальные машины:** Digital Ocean (надёжность, интеграция с AI).
    - _Альтернативы:_ Hostinger (KVM), Hetzner (дешевле).
- **Контейнеризация:** Docker (стандарт для изолированных окружений).
    - _Альтернатива:_ Podman (лицензирование).
- **CI/CD:** GitHub Actions (простота, бесплатный для публичных репозиториев).
- **Тестирование:**
    - Python: Pytest.
    - TypeScript: Jest.
- **AI‑ревью кода:** Code Rabbit (бесплатно для open‑source, детальный анализ).

## 8. Другие Инструменты Для Локального Размещения
Локальные инструменты:
- **Локальный LLM‑чат:** Open Web UI (аналог ChatGPT, локально).
    - _Альтернатива:_ Anything LLM.
- **Локальный поиск:** CRXNG.
- **Запуск LLM:** Ollama (простота, авто‑использование GPU).
    - _Альтернативы:_ VLM, Light LLM.
- **HTTPS/TLS:** Caddy (простота).
    - _Альтернативы:_ Traefik, Nginx.

## 9. Заключительные Замечания
**Ключевые выводы:**
1. Выбирайте инструменты под свои задачи, а не «потому что модно».
2. Гибкость важна, но стабильность стека экономит время.
3. Фокус на решении проблем, а не на изучении инструментов.
4. Open‑source и самохостинг — приоритет для контроля над данными.

**Финальная рекомендация:** используйте этот обзор как справочник для заполнения пробелов в вашем стеке, а не как догму.
