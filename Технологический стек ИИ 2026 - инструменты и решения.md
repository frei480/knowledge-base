# Обзор Используемого Технологического Стека: Инструменты И Платформы
Вот подробный обзор технологического стека для «Агентной инженерии» (Agentic Engineering) на 2025–2026 годы, основанный на представленном видеоматериале. Этот стек охватывает полный цикл разработки: от прототипирования и создания ИИ-агентов до full-stack разработки и развертывания в продакшн.

# Обзор Используемого Технологического Стека: Инструменты И Платформы

## 1. Обзор Технического Стека Для ИИ

В современном мире разработки программного обеспечения подход «AI First» (ИИ прежде всего) становится стандартом. Представленный стек отличается стабильностью: большинство инструментов используются автором более года, что говорит об их надежности. Главная мантра при выборе технологий — **«Возможности важнее инструментов»**. Цель этого обзора — не заставить вас использовать каждый упомянутый инструмент, а предоставить проверенный набор решений, чтобы вы могли сосредоточиться на решении проблем, а не на поиске технологий.

## 2. Ядро Технического Стека

Это фундаментальные технологии, которые используются практически во всех типах приложений, от простых скриптов до сложных агентных систем.

*   **База данных: Postgres.** Стандарт индустрии. Используется как основное хранилище данных. Основные платформы для хостинга: **Supabase** (за богатый функционал) и **Neon** (за отличную масштабируемость).
*   **Кэширование: Redis.** Обеспечивает молниеносную скорость. В качестве Open Source альтернативы рассматривается **Valkey**.
*   **ИИ-кодинг: Claude Code.** Основной ассистент для написания кода, работающий в связке с **Archon** (инструмент для управления знаниями и задачами). Альтернативы: Cursor, Codex.
*   **Прототипирование: n8n.** Мощная no-code платформа с фокусом на ИИ. Позволяет быстро тестировать гипотезы и создавать рабочие процессы перед написанием кода. Open Source и self-hostable.

## 3. Основной Стек Для Агентов ИИ

Инструменты, необходимые для создания, управления и мониторинга автономных агентов.

*   **Фреймворк для агентов: Pydantic AI.** Обеспечивает гибкость, строгую типизацию и контроль, оставаясь простым в использовании. Позволяет легко переключаться между провайдерами LLM.
*   **Мульти-агентный фреймворк: LangGraph.** Используется для сложных сценариев, где требуется управление состоянием, цикличность и маршрутизация между несколькими агентами. Отлично работает в связке с Pydantic AI.
*   **Инструментарий и авторизация: Arcade.** Решает сложнейшую задачу авторизации агентов в сторонних сервисах (например, доступ к Gmail или GitHub через OAuth) и обеспечивает безопасность использования инструментов. Также поддерживает создание серверов MCP (Model Context Protocol).
*   **Наблюдаемость (Observability): LangFuse.** Критически важный компонент для продакшна. Позволяет отслеживать трейсы, стоимость запросов, латентность и качество работы агентов. Open Source.

## 4. Инструменты Для Агентов RAG

Retrieval-Augmented Generation (RAG) требует специализированных инструментов для работы с данными.

*   **Извлечение данных (ETL):**
    *   **Docling:** Для сложных документов (PDF с таблицами и диаграммами).
    *   **Crawl4AI:** Для скрапинга и очистки данных с веб-сайтов.
*   **Векторная база данных: Postgres (с pgvector).** Вместо использования отдельных решений (как Pinecone), предпочтение отдается Postgres, так как RAG часто требует и реляционных данных. Это упрощает архитектуру.
*   **Долгосрочная память: Mem0.** Позволяет агентам «запоминать» пользователей и контекст между сессиями. Легко интегрируется с Postgres.
*   **Графы знаний:**
    *   **Neo4j:** В качестве графовой базы данных (движок).
    *   **Graphiti:** Фреймворк для интеллектуального извлечения сущностей и связей из текста с помощью LLM.
*   **Оценка (Evaluation): Ragas.** Фреймворк для метрик RAG (точность, релевантность контекста и т.д.) и генерации тестовых датасетов.
*   **Веб-поиск: Brave Search.** Обеспечивает приватный поиск без отслеживания, имеет встроенный функционал для ИИ.

## 5. Инструменты Для Агентов Веб-автоматизации

Когда агенту нужно взаимодействовать с интернетом в реальном времени как пользователю.

*   **Управление браузером: Browserbase.** Управляемая инфраструктура для запуска браузеров в облаке. Включает защиту от бот-детекторов, запись сессий и отладку. Использует **Stagehand** и **Director** для управления через естественный язык.
*   **Автоматизация браузера: Playwright.** Детерминированный и надежный инструмент для тестирования и автоматизации. Есть поддержка MCP.
*   **Скрапинг:**
    *   **Crawl4AI:** Для общих задач.
    *   **Apify:** Для сложных социальных платформ (LinkedIn, Instagram, X), где трудно обойти защиту.

## 6. Технический Стек Для Разработки Приложений Full Stack

Агентам часто требуются традиционные веб-интерфейсы и API.

*   **API Фреймворк: FastAPI.** Быстрый, асинхронный, на Python (что удобно для интеграции с ИИ-кодом).
*   **Аутентификация:**
    *   **Supabase Auth:** Для большинства проектов.
    *   **Auth0:** Для корпоративных решений (SSO, сложная безопасность).
*   **Frontend:**
    *   **React + Vite:** Стандарт де-факто.
    *   **Компоненты:** Shadcn UI + Tailwind CSS.
    *   **ИИ-билдер:** **Lovable**. Позволяет генерировать красивые UI с помощью промптов.
    *   **Простой UI:** **Streamlit**. Для быстрых демо на Python без знания фронтенда.
*   **Мониторинг:** **Sentry**. Для отслеживания ошибок в реальном времени.
*   **Платежи:** **Stripe**. Лучший опыт для разработчиков и документация.

## 7. Инструменты/платформы Для Развертывания И Инфраструктуры

Как код попадает в продакшн.

*   **Платформа развертывания: Render.** Простой PaaS (Platform as a Service) с автоматическим деплоем из Git. Альтернатива Heroku.
*   **GPU Платформа: RunPod.** Надежный и дешевый доступ к GPU для запуска локальных моделей в облаке.
*   **Виртуальные машины (VPS): DigitalOcean.** Для случаев, когда нужен полный контроль над сервером (например, хостинг Local AI package).
*   **Контейнеризация: Docker.** Индустриальный стандарт для упаковки приложений. Решает проблему «работает на моей машине».
*   **CI/CD: GitHub Actions.** Автоматизация тестирования и деплоя прямо в репозитории.
*   **Тестирование:**
    *   **Pytest:** Для Python.
    *   **Jest:** Для JavaScript/TypeScript.
*   **AI Code Review: CodeRabbit.** Автоматический обзор пулл-реквестов с поиском уязвимостей (бесплатно для Open Source).

## 8. Другие Инструменты Для Локального Размещения

Для тех, кто предпочитает полный контроль и приватность (Self-hosted).

*   **Чат-платформа: Open WebUI.** Локальный аналог ChatGPT с поддержкой RAG и пользовательских агентов.
*   **Поиск: SearXNG.** Мета-поисковая система, агрегирующая результаты из разных источников, полностью приватная.
*   **Запуск LLM: Ollama.** Самый простой способ запускать модели (Llama 3, Mistral и др.) локально.
*   **Прокси/HTTPS: Caddy.** Веб-сервер с автоматическим получением SSL-сертификатов. Проще в настройке, чем Nginx.

## 9. Заключительные Замечания
**Ключевые выводы:**
1. Выбирайте инструменты под свои задачи, а не «потому что модно».
2. Гибкость важна, но стабильность стека экономит время.
3. Фокус на решении проблем, а не на изучении инструментов.
4. Open‑source и локальный хостинг — приоритет для контроля над данными.

**Финальная рекомендация:** используйте этот обзор как справочник для заполнения пробелов в вашем стеке, а не как догму.
