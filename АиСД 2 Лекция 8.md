# Лекция 8: Минимальные Остовные Деревья (MST)

## 1. Определения И Постановка Задачи
*   **Дерево** — связный граф без циклов. В дереве из $N$ вершин всегда ровно $N-1$ ребро.
*   **Задача о минимальном остове:** Во взвешенном неориентированном графе найти остовное дерево (подграф, содержащий все вершины и являющийся деревом), сумма весов ребер которого минимальна.
*   **Применение:** Проектирование сетей (например, прокладка кабеля), где нужно обеспечить связность всех узлов с минимальными затратами.

## 2. Лемма О Безопасном Ребре
Это фундаментальное утверждение, на котором базируются все алгоритмы поиска MST (Прима, Крускала, Борувки).

*   **Формулировка:** Пусть $S$ — подмножество ребер некоторого минимального остова. Эти ребра разбивают граф на компоненты связности. Пусть $C$ — одна из таких компонент. Рассмотрим все ребра, соединяющие $C$ с остальной частью графа ($V \setminus C$).
    *   **Утверждение:** Самое дешевое ребро $e$ среди исходящих из $C$ можно безопасно добавить в $S$ (оно будет принадлежать какому-то минимальному остову).
*   **Доказательство (от противного):**
    1.  Предположим, $e=(u, v)$ не входит в MST $T$.
    2.  Так как $T$ — дерево, между $u$ и $v$ в нем есть единственный путь.
    3.  Этот путь должен в какой-то момент покинуть компоненту $C$ по другому ребру $e'$.
    4.  Так как $e$ — минимальное исходящее, то $weight(e) \le weight(e')$.
    5.  Заменим $e'$ на $e$ в дереве $T$. Получим новое дерево $T'$, вес которого не больше $T$. Значит, $e$ может входить в минимальный остов.

## 3. Алгоритм Прима
Алгоритм наращивает одну компоненту связности, начиная с произвольной вершины.

### Принцип Работы:
1.  Начинаем с произвольной вершины (например, 1). Изначально множество $S$ пусто.
2.  На каждом шаге ищем **самое дешевое ребро**, соединяющее уже построенную часть дерева с вершиной, еще не входящей в него.
3.  Добавляем это ребро и новую вершину в дерево.
4.  Повторяем, пока не охватим все вершины.

### Реализация И Асимптотика:
Поддерживаем массив `D[v]` — минимальный вес ребра, соединяющего текущий остов с вершиной $v$ (для вершин в остове пометка, что они уже там).

1.  **Наивная реализация:**
    *   Ищем минимум в массиве `D` линейным проходом ($O(N)$).
    *   Обновляем соседей добавленной вершины ($O(deg(v))$).
    *   **Итого:** $O(N^2 + M) = O(N^2)$. Эффективно для плотных графов ($M \approx N^2$).
2.  **С использованием кучи (Heap):**
    *   Храним `D` в приоритетной очереди (как в Дейкстре). Извлечение минимума и `decrease_key`.
    *   **Итого с бинарной кучей:** $O(M \log N)$.
    *   **Итого с кучей Фибоначчи:** $O(M + N \log N)$ (теоретически быстрее).

## 4. Алгоритм Крускала
Алгоритм рассматривает ребра глобально, от самых дешевых к дорогим.

### Принцип Работы:
1.  **Сортируем все ребра** по возрастанию веса.
2.  Идем по отсортированному списку.
3.  Если текущее ребро соединяет **разные** компоненты связности — берем его в остов и объединяем компоненты.
4.  Если вершины ребра уже лежат в одной компоненте — пропускаем (иначе образуется цикл).

### Система Непересекающихся Множеств (СНМ / DSU)
Для быстрой проверки связности и объединения компонент используется структура данных СНМ.
*   Каждое множество — это корневое дерево (лес).
*   **Операции:**
    *   `get(v)`: найти корень (идентификатор множества).
    *   `unite(u, v)`: объединить множества.
    *   `same(u, v)`: проверка `get(u) == get(v)`.

**Эвристики для ускорения СНМ:**
1.  **Ранговая эвристика (подвешивание за размер/ранг):** Всегда подвешиваем меньшее дерево к большему. Гарантирует глубину дерева $O(\log N)$.
2.  **Сжатие путей (Path compression):** При выполнении `get(v)` переподвешиваем все вершины на пути поиска непосредственно к корню.

**Теорема:** При использовании обеих эвристик амортизированное время одной операции — $O(\alpha(N))$, где $\alpha$ — обратная функция Аккермана (для любых разумных чисел $\alpha(N) \le 4$).

### Асимптотика Крускала:
*   Сортировка ребер: $O(M \log M)$ (или быстрее, если веса малые — сортировка подсчетом).
*   Запросы к СНМ ($2M$ операций): $O(M \cdot \alpha(N))$.
*   **Итого:** $O(M \log M)$ (определяется сортировкой).

## 5. Алгоритм Борувки
Хронологически самый первый алгоритм. Работает итеративно, сразу сжимая множество компонент.

### Принцип Работы:
1.  Изначально каждая вершина — отдельная компонента.
2.  **Шаг 1:** Для **каждой** компоненты находим самое дешевое исходящее из неё ребро.
    *   *Тонкость:* При равенстве весов сравниваем индексы ребер, чтобы выбор был однозначным.
3.  **Шаг 2:** Добавляем все выбранные ребра в остов.
4.  **Шаг 3:** Сжимаем компоненты связности по добавленным ребрам. В новом графе вершинами становятся бывшие компоненты.
    *   Кратные ребра между компонентами заменяем одним самым дешевым. Петли удаляем.
5.  Повторяем рекурсивно, пока не останется одна вершина.

### Корректность:
*   Выбранные ребра образуют **функциональный граф** (из каждой вершины 1 ребро).
*   Благодаря правилу сравнения по индексу (при равенстве весов), циклы длины > 2 невозможны.
*   Единственные возможные "циклы" — это ребра между двумя компонентами туда и обратно (длины 2), что по факту одно и то же ребро.
*   Применяется лемма о безопасном ребре сразу ко всем компонентам.

### Асимптотика:
*   На каждой итерации количество компонент уменьшается **минимум в 2 раза** (так как каждая компонента соединится хотя бы с одной другой).
*   Значит, всего будет $O(\log N)$ фаз.
*   Каждая фаза (поиск минимумов, DFS для сжатия) выполняется за линейное время от текущего размера графа $O(M)$.
*   **Итого:** $O(M \log N)$.

## Сравнение Алгоритмов

| Алгоритм | Сложность | Особенности |
| :--- | :--- | :--- |
| **Прима (наивный)** | $O(N^2)$ | Лучший для плотных графов ($M \sim N^2$). |
| **Прима (Heap)** | $O(M \log N)$ | Хорош для разреженных графов. |
| **Крускала** | $O(M \log M)$ | Прост в реализации с СНМ, эффективен для разреженных графов. |
| **Борувки** | $O(M \log N)$ | Хорош для параллельных вычислений, используется в специфических задачах. |
