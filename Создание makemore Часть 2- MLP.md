00:00 Введение и проблема биграммной модели

• На [[Подробное введение в языковое моделирование - создание makemore|прошлой лекции]] была реализована биграммная модель языка с использованием подсчёта и простой нейронной сети.

00:56 Ограничения биграммной модели при увеличении контекста

• При увеличении длины контекста размер таблицы экспоненциально растёт.
• Пример: при учёте двух символов количество строк в матрице увеличивается до 729.
• Модель становится неэффективной из-за избыточного количества вариантов.

01:48 Переход к многослойной модели персептрона

• Планируется реализация многослойной модели персептрона для предсказания следующего символа.
• Подход основан на работе Бенгио и др. 2003 г., которая оказала большое влияние на область.

02:43 Встраивание слов в 30-мерное пространство

• Каждое слово связывается с 30-мерным векторным представлением.
• Слова инициализируются случайным образом и настраиваются с помощью обратного распространения.
• В процессе обучения слова с похожими значениями оказываются рядом в пространстве.

03:59 Принцип работы модели

• Модель использует многослойную нейронную сеть для предсказания следующего слова.
• Обучение максимизирует логарифмическую вероятность обучающих данных.
• Пример с фразой «собака бежала в пустом месте» показывает, как модель обобщает знания через встраивания.

05:47 Структура нейронной сети

• Входной слой содержит 30 нейронов для каждого из трёх предыдущих слов.
• Скрытый слой — гиперпараметр, определяющий размер сети.
• Выходной слой содержит 17 нейронов для каждого возможного следующего слова.
• Слой softmax нормализует и суммирует логиты, создавая распределение вероятностей.
